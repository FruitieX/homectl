What changes in both concepts

  • Separate everyday navigation from the longer settings list. Distinguish the parent section from the actual selected page.
  • Align every icon and label. Keep long names on one line at normal desktop size; let text wrap when needed in the eventual app.
  • Order settings by purpose: rooms and devices first, then connections; scenes and routines first within automations.
  • Keep the whole settings catalog reachable. Phone group shortcuts jump directly to Home, Automations, Appearance or Maintenance.
  • Open navigation brings the current category into view. Close dismisses the drawer; choosing a page closes it too.
  • Search remains global, with Ctrl+K and a single command palette.
  • Use the same navigation on the floorplan, routine editors, dashboard and settings. Floorplan tabs remain in the phone AppBar beside the assistant button.
