Pause to change controls

Color stays active as you leave the wheel. Pause in the ring for 320 ms to arm brightness, then move around it. Pause back inside the wheel to return to color.

Pull the handle, then slide vertically

Drag through the right-hand handle and pull 14 px farther out to open the brightness rail. Slide up or down. Pull through the handle again to return to color.

Try it with a finger

Press the color wheel and keep holding while you switch and adjust. “Play gesture” traces the same continuous path. Values are local to this page.

Shared behavior

Only the active control changes. Switching freezes the other value and never jumps brightness. Release keeps the popover open; tap outside to dismiss. Hold the center power button to dismiss. The three-light selection is preserved.
